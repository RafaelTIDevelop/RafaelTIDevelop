# Olá, eu sou o Rafael da Silva 👋

Sou **Desenvolvedor Full Stack**, pós-graduado em **Desenvolvimento Full Stack e Cloud Computing** (Gran Centro Universitário), graduado em **Gestão de Tecnologia da Informação** (UCB) e **Técnico em Informática** (ETB).

Foco no desenvolvimento de aplicações web modernas, escaláveis e orientadas à simplicidade, combinando arquiteturas serverless, boas práticas de código e foco na experiência do usuário.

---

### 🚀 Projetos em Destaque

* **[Meu Voto Fez](https://meuvotofez.com.br)** - Plataforma cívica responsiva voltada para acompanhamento eleitoral e participação cidadã no Distrito Federal e no Brasil, construída com foco em alta performance e custo zero de manutenção.
* **MaisHábito** - Aplicação web gamificada para gestão de hábitos e desafios diários, desenvolvida com React, Node.js, Express e PostgreSQL (projeto de conclusão de pós-graduação).
* **PDF Ouvidoria PWA** - Progressive Web App voltado para geração ágil de documentos PDF em fluxos de ouvidoria.
